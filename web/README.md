# Unity Devlog & Portfolio (web)

Notion 데이터베이스를 CMS로 쓰는 Next.js 포트폴리오 / 개발 일지 사이트.

- 설계: [`../docs/PRD.md`](../docs/PRD.md), 로드맵: [`../docs/ROADMAP.md`](../docs/ROADMAP.md)
- 환경변수: `.env.example`을 복사해 `.env.local` 작성 (`NOTION_TOKEN`, `NOTION_DATABASE_ID`)
- 실행: `npm run dev` / 검증: `npm run format:check && npm run lint && npm run typecheck && npm run build`
